# 系统架构

```text
合成任务 -> task_router -> 允许 / 审批 / 拒绝
允许的模拟执行 -> dryrun_lifecycle -> 事件与对账记录
允许的证据 -> evidence_classifier -> 可支持 / 被阻断的声明
晋级请求 -> promotion_gate -> 所需证据、检查与状态上限
所有场景 -> public_demo -> JSON 记录，执行权限始终为 false
```

研究平面负责问题、候选与验证；执行平面在公开版中只模拟 intent、event 和对账。
治理平面限制证据能支持的声明，并审核晋级条件。编排负责路由，不能覆盖治理或创造权限。

任务是否允许执行，与产物能支持什么声明，是两个独立问题。公开状态上限为
research_only；完整研究材料不会自动跨越上限，实盘请求在生命周期运行前就被拒绝。

没有策略、市场数据或交易接入。独立仓库沿用公开代码语义，没有新增金融执行能力。
