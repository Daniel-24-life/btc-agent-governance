# v1.1 记录查看器验证

日期：2026-10-15。独立无登录资料的 Chromium，本地静态服务器读取公开 `sample.fake.json`。只测试当前支持的浅色页面，不宣称完整 WCAG 合规。

| 检查 | 结果 | 范围 |
| --- | --- | --- |
| 320、375、768、1440 CSS px | pass | 稳定截图、页面无横向溢出 |
| 200% 文字放大与文字间距覆盖 | pass | 375px，全元素计算字号加倍；间距覆盖1.5/.12em/.16em/2em |
| 原生键盘入口、减少动态效果 | pass | Tab 与原生场景按钮/JSON 折叠，reduced-motion |
| 默认模拟生命周期与四场景切换 | pass | 默认 dry_run_lifecycle；四个场景的原始 JSON 与样例逐项一致 |
| 未运行、阻断、执行权限 | pass | null 阶段不冒充已运行；四场景权限均 false |
| JSON 窄屏展开 | pass | 内容在独立代码区滚动，不撑宽页面 |
| 样例与公开 Python 运行器一致 | pass | 自动测试覆盖；动态时间字段不作固定值比较 |
| 浏览器脚本错误 | pass | 上述流程无 pageerror |
| 真实下单、模型、交易所、Safari、屏幕阅读器 | not tested | 未接入，不属于查看器能力 |

截图为历史合成记录的静态查看，不是实时任务运行。见 [UI_AUDIT.md](UI_AUDIT.md)。
